# 献立ノート

夜の献立とお買い物・月予算を記録するシンプルなWebアプリです。ビルド不要（HTMLファイル1枚+アイコン）なので、そのままGitHub Pagesで公開できます。

## ファイル構成

```
index.html        アプリ本体（これだけで動きます）
manifest.json      ホーム画面に追加したときの名前・アイコン設定
icons/             アプリアイコン
```

## GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作成する(例：`meal-notebook`)
2. このフォルダの中身(`index.html`, `manifest.json`, `icons/`)をそのままリポジトリ直下にアップロードする
   - GitHubの画面から「Add file」→「Upload files」でドラッグ&ドロップでOK
3. リポジトリの「Settings」→左メニューの「Pages」を開く
4. 「Build and deployment」の「Source」を `Deploy from a branch` にし、Branchを `main` / フォルダを `/(root)` にして保存
5. 数分待つと、ページ上部に公開URLが表示されます（例：`https://ユーザー名.github.io/meal-notebook/`）

## iPhoneでアプリのように使う手順

1. iPhoneのSafariで、上記の公開URLを開く
2. 画面下の共有ボタン(四角から矢印が出ているアイコン)をタップ
3. 「ホーム画面に追加」を選ぶ
4. 名前を確認して「追加」

ホーム画面にアイコンが追加され、タップするとブラウザのアドレスバーなどが表示されない、アプリのような見た目で開きます。

## データについて

- データは**その端末のブラウザの中だけ**に保存されます(サーバーには送信されません)。
- 同じiPhoneでも、SafariとChromeなど別のブラウザを使うとデータは共有されません。ホーム画面に追加したアイコンから開けば、いつも同じデータが表示されます。
- 機種変更やブラウザが変わるときは、アプリ内「カレンダー」タブ下部の「書き出し」でJSONファイルを保存し、新しい端末で「読み込み」から取り込んでください。

## 注意点

- 見た目のフォント(明朝体)はGoogleフォントを読み込んでいるため、初回表示時にネット接続が必要です。
- アイコンの絵柄(「献」の文字)を変えたい場合は、`icons/`フォルダの画像を同じファイル名で好きな画像に差し替えてください(`icon-192.png`は192×192px、`icon-512.png`は512×512px、`apple-touch-icon.png`は180×180px推奨)。
